# 🤟 Sign Language Recognition using MediaPipe and Random Forest

A real-time Sign Language Recognition system that recognizes American Sign Language (ASL) alphabet gestures using **MediaPipe Hand Landmarks** and a **Random Forest Machine Learning model**. The application provides live webcam prediction through a Streamlit web interface and automatically forms words from recognized gestures.

---

## Features

- Real-time webcam sign language recognition
- MediaPipe hand landmark detection
- Random Forest classifier
- Prediction confidence display
- Automatic word formation
- Support for **Space** and **Delete** gestures
- Interactive Streamlit web application

## Dataset

This project uses the **ASL Alphabet Dataset** containing images of American Sign Language (ASL) alphabet gestures.

**Dataset Source:**

https://www.kaggle.com/datasets/grassknoted/asl-alphabet

The original dataset is **not included** in this repository due to its size.

---

## Model

The trained Random Forest model (`sign_model.pkl`) is **not included** in this repository because it exceeds GitHub's file size limit.

The processed landmark dataset (`landmarks.csv`) is also excluded to keep the repository lightweight.

Both files can be generated by following the installation steps below.

## Installation

Clone the repository

```bash
git clone https://github.com/JAIKRISHNA2007/Sign-Language-Recognition.git
```

Move into the project folder

```bash
cd Sign-Language-Recognition
```

Install dependencies

```bash
pip install -r requirements.txt
```

Download the ASL Alphabet Dataset from:

https://www.kaggle.com/datasets/grassknoted/asl-alphabet

Extract the dataset into:

```text
data/raw/asl_alphabet_train/
```

Generate the landmark dataset

```bash
python src/extract_landmarks.py
```

Train the Random Forest model

```bash
python src/train_model.py
```

Run the application

```bash
streamlit run app.py
```

---

## Usage

1. Launch the Streamlit application.
2. Click **Start** to enable the webcam.
3. Position your hand clearly in front of the camera.
4. Perform an ASL alphabet gesture.
5. View the predicted letter and confidence score.
6. Hold a gesture briefly to automatically build words.
